# ЯМайстер — сайт майстерні

Статичний багатосторінковий сайт локальної майстерні у Києві.

## Структура

- `index.html` — головна сторінка
- `services/` — окремі сторінки послуг
- `assets/` — стилі, JavaScript і зображення

## Локальний запуск

Сайт не потребує встановлення залежностей або збірки. Відкрийте `index.html` у браузері або запустіть будь-який локальний статичний сервер.

## Публікація

Репозиторій готовий до публікації через GitHub Pages, Cloudflare Pages, Netlify або Vercel. Для GitHub Pages виберіть гілку `main` і папку `/ (root)`.

## Технології

HTML, CSS і JavaScript без сторонніх фреймворків.
